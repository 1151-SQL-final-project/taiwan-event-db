# web

網頁（HTML、CSS、JavaScript）。

目前的 `index.html` 是**串接測試版**（沒有設計，功能可用）：登入註冊（可選使用者或商家）、搜尋（含學習類／休閒類）、活動詳情、收藏。

待製作的正式頁面：

- 使用者頁面（邦妤）：登入、註冊、搜尋、活動詳情、我的收藏
- 商家後台（昱妏）：我上架的活動、上架／修改活動（含多筆優惠、新增場館）
- 管理員後台（昱妏）：待審核清單（通過／退回）、違規下架、重新上架、統計

商家、管理員用的 API 路徑與參數見根目錄 README 的「API 一覽」（目前回傳 501，等 SQL 寫好後接上）。
選單可以依登入角色（`/api/me` 的 `UserRole`）顯示，但真正的權限檢查在後端。
