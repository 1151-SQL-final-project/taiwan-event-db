# web

網頁（HTML、CSS、JavaScript）。

| 檔案 | 內容 |
|---|---|
| `index.html` | **首頁**：只有 logo、名稱「探點」與介紹。選單的「找活動」目前連到串接測試頁 |
| `test.html`、`app.js` | **串接測試頁**（沒有設計，功能可用）：登入註冊（可選使用者或商家）、搜尋（含學習類／休閒類）、活動詳情、收藏。網址可以帶搜尋條件，例如 `test.html?region=北部` |
| `style.css` | 兩頁共用的樣式與配色 |
| `logo.png`、`favicon.png` | logo（去背）與瀏覽器分頁圖示 |

## 配色

取自 logo：米白底 `#f7f4ee`、深藍 `#203a55`（主色：按鈕、選取狀態）、赭紅 `#b06040`（點綴、優惠）。
顏色都是 `style.css` 開頭的變數，深色模式只換變數；正式頁面請直接沿用這組變數。
logo 是去背的，深色模式下會墊一個米白圓底（`--logo-plate`），深藍線條才看得到。
