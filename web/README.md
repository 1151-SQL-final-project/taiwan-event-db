# web

網頁（HTML、CSS、JavaScript），單頁式，網址 `#` 後面決定顯示哪一頁（見 `js/app.js` 開頭）。

程式依頁面分在 `js/` 裡，`index.html` 依序載入（一般的 `<script>`，彼此共用最上層的變數與函式，不需要打包工具）：

| 檔案 | 內容 |
|---|---|
| `js/core.js` | 共用工具（日期、票價、跳脫）、登入狀態、呼叫後端的 `api()`、選單 |
| `js/cards.js` | 活動卡片、類別插圖、即將開賣與早鳥即將截止的活動列 |
| `js/home.js`、`js/search.js`、`js/event.js`、`js/saves.js`、`js/stats.js` | 首頁、找活動、活動詳情、我的收藏、數據 |
| `js/auth.js` | 登入／註冊、帳號頁、後台共用的角色檢查 |
| `js/merchant.js`、`js/admin.js` | 商家後台、管理員後台 |
| `js/app.js` | 路由與啟動（最後載入，因為要用到前面所有頁面） |

新增頁面時：在對應的檔案加函式，再到 `js/app.js` 的 `routes` 加一行；新增檔案要記得加進 `index.html`（放在 `js/app.js` 前面）。

頁面：

- 首頁 `#/`：只有 logo、名稱「探點」與介紹；找活動在 `#/search`
- 使用者頁面（邦妤）：`#/search` 找活動（地區、日期、類別／學習類、優惠篩選、活動狀態：進行中／即將開始或開賣／早鳥即將截止；即將開賣、早鳥即將截止區塊）、活動詳情（開賣時間）、我的收藏與優惠截止、開賣提醒、數據、登入註冊
- 商家後台（昱妏）：`#/merchant` 我上架的活動、`#/merchant/new` 上架活動（含優惠、開賣時間、新增場館）；被退回的活動顯示退回理由；送出前有相似活動會先提醒
- 管理員後台（昱妏）：`#/admin` 審核（通過／退回時跳出彈窗勾選理由；有相似的已上架活動時顯示重複提醒）、違規下架、重新上架、統計

選單依登入角色顯示；真正的權限檢查在後端。


配色取自 logo（`logo.png`，去背；深色模式下墊米白圓底）：米白底 `#f7f4ee`、深藍 `#203a55`（主色）、赭紅 `#b06040`（點綴、優惠）。顏色都是 `style.css` 開頭的變數，深色模式只換變數。
